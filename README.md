# Python API Challenge: WeatherPy and VacationPy

## Overview

This project uses live API data to analyze weather conditions in cities around the world and identify potential vacation destinations.

The project is divided into two Jupyter notebooks:

* **WeatherPy** retrieves and analyzes worldwide weather data.
* **VacationPy** uses the weather results to identify cities with desirable conditions and locate nearby hotels.

## WeatherPy

`WeatherPy.ipynb` generates a global collection of cities using randomly selected latitude and longitude coordinates. It then requests current weather information for those cities from the OpenWeatherMap API.

The collected data includes:

* Latitude and longitude
* Maximum temperature
* Humidity
* Cloudiness
* Wind speed
* Country
* Date of observation

The cities are divided into Northern and Southern Hemisphere DataFrames. Linear regression analysis is then used to examine the relationship between latitude and:

* Maximum temperature
* Humidity
* Cloudiness
* Wind speed

A reusable Python function creates, displays, and saves all eight regression plots. This reduces duplicated code and makes the analysis easier to maintain.

## VacationPy

`VacationPy.ipynb` uses the city data generated by WeatherPy to help identify possible vacation destinations.

The notebook will:

* Display cities on an interactive map.
* Filter cities according to preferred weather conditions.
* Use the Geoapify API to locate a nearby hotel for each qualifying city.
* Create a destination map containing city, country, weather, and hotel information.

## Project Workflow

This project follows the development workflow:

> Structure it. Secure it. Verify it. Commit it. Then code.

API credentials are stored locally in a `.env` file and loaded through `config.py`. The `.env` file is excluded from Git so private API keys are not published to GitHub.

A safe `.env.example` file is included to document the required environment variables:

```text
OPENWEATHER_API_KEY=
GEOAPIFY_API_KEY=
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/a1990alpalo/python-api-challenge-2023.git
cd python-api-challenge-2023
```

2. Create and activate a virtual environment.

3. Install the required packages:

```bash
python -m pip install -r requirements.txt
```

4. Create a `.env` file in the project root:

```text
OPENWEATHER_API_KEY=your_openweather_key
GEOAPIFY_API_KEY=your_geoapify_key
```

5. Open and run `WeatherPy.ipynb` before running `VacationPy.ipynb`.
